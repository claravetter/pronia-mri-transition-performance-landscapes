# Tests and reproducibility

Supported test environment: macOS, R 4.5.2 and Python 3.14.4, using the exact versions in `renv.lock` and `requirements.lock`. Restore dependencies as described in [README](README.md). [VALIDATION_SOURCE.json](VALIDATION_SOURCE.json) records SHA-256 values for the tested source and configuration.

Run from the repository root:

```sh
Rscript --vanilla tests/test_statistics.R
Rscript --vanilla tests/test_production.R
.venv/bin/python -m unittest discover -s tests -p 'test_*.py' -v
```

The suites contain 98 production assertions, two statistics test groups and 19 Python tests. They check input contracts and identity reconciliation, clinical-group selection, window boundaries and support, statistical estimators, resampling accounting and random streams, calibration, output boundaries and anatomical rendering provenance. Inputs are generated by the tests; no participant data are required.

For an end-to-end computation and its output assertions:

```sh
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 .venv/bin/python python/run_pipeline.py synthetic --output ../local_runs/test_run --cores 2
Rscript --vanilla tests/verify_computed_run.R ../local_runs/test_run
```

This computes the configured analyses and statistical figures from newly generated input. The statistical run has 22 output assertions. Optional anatomy tests require the [external assets](docs/ANATOMY_INPUTS.md). The MRIcroGL launcher requires a new output directory and verifies all four panels and the completion marker; its timeout bounds incomplete renders. Empirical runs require authorized inputs and the full configuration; generated-data tests do not validate historical model training, cohort harmonization or clinical use.

Resampling streams are indexed independently of worker scheduling. Use one worker on Windows. Floating-point results can vary with numerical libraries and thread settings; numerical comparisons use explicit tolerances.
